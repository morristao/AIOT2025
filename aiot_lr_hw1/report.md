# Report (Prompt & Process)

本報告補充作業要求的「**prompt 與過程**」。

- **Prompt 摘要**：請用 Python 製作一個可互動的線性回歸示範，允許調整 `a,b,noise,n_points`，並部署成網站。
- **方法選擇**：採 Streamlit 作為前端互動框架；以 `numpy.linalg.lstsq` 實作 OLS；用 `matplotlib` 做圖。
- **實作步驟**：
  1. 定義側欄參數（含隨機種子、x 範圍、離群點比例/強度）。
  2. 依參數產生合成資料並可選地注入離群值。
  3. 使用最小平方法估計 `a_hat, b_hat`，計算 MSE 與 R²。
  4. 視覺化散佈與擬合線；輸出前 20 筆資料表；提供 CSV/JSON 下載。
  5. 於頁面底部簡述 CRISP‑DM 對應。
- **實驗觀察**：噪音越大、離群點越多，`R²` 通常降低，估計係數偏移加劇。
- **限制**：為簡潔未納入交叉驗證與置信區間；若使用真實資料，需再做特徵工程與資料切分。
