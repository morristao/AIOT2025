# HW2: Multiple Linear Regression — House Prices

## 目標
以 Kaggle 「House Prices」資料集為例，進行多元線性回歸分析，並遵循 CRISP-DM 流程完成資料理解、建模、評估與部署。

## 檔案內容
- 7113056099_hw2.ipynb: 主程式 (含 CRISP-DM 流程)
- report_template.md: 報告範本 (含 GPT 與 NotebookLM 區塊)
- requirements.txt: 套件需求

## 執行方式
1. 下載 Kaggle `train.csv` 放入 dataset/
2. 安裝套件：
   ```bash
   pip install -r requirements.txt
   ```
3. 開啟 Notebook 或 Colab 執行。
